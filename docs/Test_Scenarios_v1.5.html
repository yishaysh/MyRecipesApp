# פעולה / צעד בדיקה תוצאה מצופה סטטוס
1 נסה לבצע קריאת API ישירה אל /api/v1/admin/stats ללא Bearer Token. השרת מחזיר שגיאת 401 Unauthorized וחוסם את הגישה. [ ] עבר
2 בדיקת פתיחת קישורי מקור: נסה לפתוח קישור עם סכמה לא מאובטחת. הפונקציה isSafeHttpUrl מזהה את הקישור הלא תקין ומחליפה אותו ב-# ללא הרצת סקריפט זדוני. [ ] עבר
3 בדיקת טוקן גוגל מזויף: נסה לשלוח ID Token שהונפק לאפליקציה זרה. שרת ה-Auth דוחה את הטוקן בגלל בדיקת Audience & azp קפדנית, ומחזיר שגיאה ללא יצירת משתמש. [ ] עבר
